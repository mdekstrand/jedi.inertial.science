# JEDI web site

This web site is built with [Zola][] and the [Academic Workshop theme][theme].  It currently
requires Zola 0.22.1 or older, the academic workshop theme has not been updated to Zola 0.23.

A compatible version can be installed with [aqua][].  To set up the environment and start previewing
the site:

```console
$ aqua install
$ aqua exec zola serve
```

Alternatively, you can directly install Zola and run `zola serve.

[Zola]: https://www.getzola.org/
[theme]: https://github.com/aterenin/academic-workshop
[aqua]: https://aquaproj.github.io/
